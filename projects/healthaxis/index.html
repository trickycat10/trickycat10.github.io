HealthAxis

I built a clinic platform with an Angular portal, a Blazor administration console and an ASP.NET Core API backed by SQL Server.

C# · ASP.NET Core · Angular

Application architecture

The Angular portal and Blazor admin console use an API that accesses SQL Server through Entity Framework Core. JWT authentication protects access.

Background work

I used RabbitMQ and MassTransit for event-driven workflows, keeping message handling separate from request handling.

Testing and operations

I covered services with xUnit tests and added centralized logging with Elasticsearch and Kibana. The AWS deployment design uses Elastic Beanstalk, RDS and S3.
